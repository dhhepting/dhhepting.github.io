Diffusion shader check

Runs diffusionExplorer/shaders/step.frag on this computer's GPU for every rule, texture format and edge rule, and compares the result texel by texel with the CPU reference in seeds.mjs. Tolerances: RGBA32F 1e-5, RGBA16F 4e-3, RGBA8 one step of 1/255. render5's unstable rate (0.5) is checked on one step only in 16 and 8 bits: it multiplies any rounding difference by up to 3 per step.
