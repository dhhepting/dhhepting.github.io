Chapter 6 shading comparisons

Each page puts two of the Chapter 6 programs side by side in WebGL2, driven by one set of controls, with a difference image and an informal cost comparison underneath.

  • shadedSphere1 vs shadedSphere2 Vertex normals: per-vertex shading against per-fragment shading.
  • shadedSphere3 vs shadedSphere4 True (face) normals: per-vertex shading against per-fragment shading.
  • shadedSphereEyeSpace vs shadedSphereObjectSpace The same lighting computed in eye coordinates and in object coordinates.
  • shadedCubeHalfway: Phong vs modified Blinn-Phong Reflection-vector specular against halfway-vector specular, with the cost of each.
