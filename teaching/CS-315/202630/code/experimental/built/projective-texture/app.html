How it works

The projector is a second camera. Each vertex is sent through the light's view and projection matrices, then through a bias that maps clip space [-1, 1] to texture space [0, 1]:

uTextureMatrix = Bias * P_light * V_light * Model
vProjTexCoord  = uTextureMatrix * position
slide = textureProj(uProjectedTexture, vProjTexCoord)

textureProj divides by the fourth component q. Points behind the projector have q < 0 and would receive a mirror image of the slide, so the fragment shader switches them off. Shadows reuse the same coordinates: the scene is first rendered from the projector into a depth map, and a fragment is in shadow when something nearer to the projector was recorded at its (s, t).
