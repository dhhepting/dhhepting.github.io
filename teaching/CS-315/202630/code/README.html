Code directory README

common/

  • shared ES modules (MV.mjs, initShaders*.mjs, …)
  • the most recent version of the threeJS code that is compatible with textbook examples in Chapter 9: three-r124.min.js

dist/

  • serves app’s built by Vite

experimental/

  • programs written with help from claude.ai
  • ES modules, built by Vite – run from /dist/experimental/built/ and view source from /dist/downloads/
  • single-file demos: no imports, open directly and run from /experimental/standalone/

textbook-classic/

  • textbook code as published on interactivecomputergraphics.com with minimal changes: classic-style scripts, no build
  • see /textbook-classic/ and subdirectories 02, 03, .., 11 correspond to the chapters with code examples
  • run from the in the chosen directory (source can be viewed through your browser, all files used will be linked to the and can be followed from there)
