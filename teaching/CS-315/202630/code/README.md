# Code directory README

## common/

* shared ES modules (MV.mjs, initShaders*.mjs, ...)
* the most recent version of the threeJS code that is compatible with textbook examples in Chapter 9: three-r124.min.js
  
## experimental

* programs written with help from claude.ai

## experimental/built/

* ES modules, built by Vite
* run from [/dist/experimental/built/](./dist/experimental/built/)

## experimental/standalone/

* single-file demos: no imports, open directly
* run from [/experimental/standalone/](./experimental/standalone/)
  
## textbook-classic/

* textbook code as published on [interactivecomputergraphics.com](https://interactivecomputergraphics.com/8E/Code/) with minimal changes: classic-style scripts, no build
* subdirectories 02, 03, .., 11 correspond to the chapters with code examples
* run from the <file.html> in the chosen directory (source can be viewed through your browser, all files used will be linked to the <file.html> and can be followed from there)
